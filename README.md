# Madiha Khan — Personal Portfolio Website

A responsive personal portfolio website created for **Devixo Solutions Web Development Internship — Task 01**. It introduces the developer, presents skills and education, showcases three projects, and provides contact information and a contact-form interface.

## Technologies Used
- HTML5
- CSS3
- Font Awesome 6.7.2 (icons loaded through CDN)
- SVG skill icons and local image assets

> This project uses custom HTML and CSS. No Bootstrap or Tailwind CSS framework is included.

## Website Sections
- **Home:** Introduction, name, professional tagline, profile image, and call-to-action links.
- **About:** Short introduction, education summary, career interests, and professional goal.
- **Skills:** HTML5, CSS3, JavaScript, React, and GitHub cards.
- **Education:** Saylani Web Development learning information (2025–Present).
- **Projects:** Portfolio Website, Calculator App, and To-Do List App with project links.
- **Contact:** Email, phone, location, social links, and a contact-form UI.
- **Footer:** Copyright, quick navigation, and social links.

## Responsive Design and Features
- Responsive CSS media queries for tablet and mobile layouts.
- CSS smooth scrolling.
- Navigation links to page sections.
- Hover transitions for interactive elements.
- Skill and project cards.
- Contact form UI (front-end only; no backend submission is configured).

No build tools or package installation are required.
